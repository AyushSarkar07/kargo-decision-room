# Synthetic applicants

Every CV in this folder is **synthetic**: invented people, invented employers where
needed, and `example.com` email addresses (a reserved domain that can never be a
real mailbox). They exist to test and demonstrate the pipeline without real
candidate data. They are not the 60 Kargo applications and not the 8 past hires.

| File | Applied | Purpose |
| --- | --- | --- |
| s01_strong_pm.txt | PM | Required test: clearly strong PM |
| s02_weak_spm.txt | SPM | Required test: clearly weak SPM |
| s03_ambiguous_pm.txt | PM | Required test: ambiguous, thin evidence |
| s04 … s10 | mixed | Demo population |
| s11_injection_spm.txt | SPM | Contains instruction-like text that must be ignored |
| s12_new_pm.txt, s13_new_spm.txt | PM / SPM | "Two new CVs" for the end-to-end run |
